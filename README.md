### 🚀 Featured Project

#### [Unified Hotel ERP](https://github.com/shiwali-saraswat-dev/Unified-Hotel-ERP)
*A high-concurrency hospitality management suite built to demonstrate modern Laravel 12 patterns.*

**The Core Engineering:**
* **Modernization:** A hands-on architectural transition from **Laravel 8 to Laravel 12**, utilizing the Vite asset pipeline and latest PHP 8.x features.
* **Security & IAM:** Robust **Role-Based Access Control (RBAC)** integrated with Laravel Breeze for secure, multi-tenant administration.
* **Data Integrity:** Implemented complex **Soft/Permanent Delete workflows** and strict validation logic across all modules.
* **Full-Suite Modules:** Includes Guest PMS (Room Booking), POS (Food Ordering), and BMS (Banquet Management) with a dynamic frontend.
* **UX/Performance:** Custom frontend pagination, dynamic asset loading per view, and standardized real-time notifications via SweetAlert2/Toastr.

**Stack:** Laravel 12 · Blade · MySQL · Vite · Tailwind CSS
